# Cheq PWA - Minimal Ledger UI

Cheq is a local-first finance PWA built around a monthly calendar.

## Current version

- Starts at May 2026
- Calendar-first home screen
- Minimal Ledger dark UI
- Logo splash/loading screen
- Month status banner
- Safe to Spend card
- Financial HUD cards
- Today marker ring
- Selected-day detail strip
- Transactions ledger tab
- Summary tab with color-edged KPI cards and donut charts
- Local backup/restore and CSV export

## Color meaning

- Red: cash/debit expenses
- Orange: Discover credit usage
- Blue: Amex credit usage
- Green: income

## Local-only warning

Cheq stores data in browser localStorage. Export a backup before clearing browser data, reinstalling, or changing phones.

## Run locally

Open this folder in VS Code and use the Live Server extension on `index.html`.

## Install on phone

Deploy the folder to Netlify, Vercel, or GitHub Pages. Open the deployed URL on your phone and add it to the home screen.
